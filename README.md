
# KataKoutsi

Android-sovellus karate-katojen harjoitteluun.

## Tavoite
- Katavideon valinta
- Harjoittelu puhelimen kameran avulla
- Kehon asentojen analysointi
- Palaute suorituksen jälkeen

## Rakentaminen
Android-projekti käyttää Kotlinia, Jetpack Composea, CameraX:ää ja ML Kit Pose Detectionia.
